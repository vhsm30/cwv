# Backlog B1–B4 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close every item in `BACKLOG.md` (B1–B4, D1–D10) so each Win the review found has Lock-in, and the facts that lived in five files each get one home.

**Architecture:** Three deep modules and one data table. `lib/page.mjs` parses `index.html` once into a model every assertion reads (B1). `images/slots.json` describes each image Slot once; the generator builds from it and the contract verifies markup *and* disk against it (B2). `lib/report.mjs` + `tools/run.mjs` encode the Run with two adapters, Lighthouse and recorded Report (B3). `server.py` concentrates type/compression/cache into one policy table asserted over HTTP on an ephemeral port (B4).

**Tech Stack:** Node 24 (`node:test`, no packages), Python 3.12 + Pillow (generator only), Lighthouse 13.4.1 global CLI. No package manager, no build step.

**Spec:** `BACKLOG.md` (Problem / Evidence / Shape / Wins per item). Vocabulary: `CONTEXT.md`.

## Global Constraints

- Dependency-free, framework-free, no build step. `index.html` stays hand-written.
- Vocabulary from `CONTEXT.md` in every new name and comment (Run, Report, Preview URL, Measurement Server, Win, Lock-in, Performance Contract, Storefront, Hero, Collection, Product, Bag). Avoid-list words stay out of new prose.
- Never build regexes from strings (`CLAUDE.md:104`). Mutation-check every new assertion by breaking what it guards.
- No commits: the user has not asked for one. `git mv` is fine for renames (status stays readable).
- Nobody but the main session edits `CLAUDE.md`, `CONTEXT.md`, `BACKLOG.md`, `index.html`, `llms.txt`, `images/`, `tests/performance-contract.mjs`.

## Decisions taken on the user's behalf (flag in the recap)

1. **D5:** rename the 14 Reports on disk to their own UTC `fetchTime` (`<host>-YYYYMMDDTHHMMSSZ.json`) rather than amend CONTEXT.md — the truth is inside each file, and the rule becomes an assertion over `reports/`.
2. **Rung naming is uniform:** `<slot>-<width>.<webp|jpg>`. The Hero's 1200w rungs become `hero-1200.webp` (byte-identical to today's `hero.webp`, so it is a `git mv`) and `hero-1200.jpg` (new, re-encoded from the master like every other JPEG rung). `hero.jpg` stays a master only. `hero-640.jpg` / `hero-768.jpg` are rebuilt in place by the generator (precedent: `coffee-374.webp` in the last commit). Superseded `hero.webp` is not kept as an orphan — it *is* `hero-1200.webp`.
3. **Slot table lives at `images/slots.json`** (Python `json` + Node `JSON.parse`, no build step). Per-slot WebP quality override lives there too, since it is a fact about the Slot.
4. **All assertions run under one command:** `node --test "tests/**/*.mjs"`. Server assertions are Node spawning the real `python server.py 0`, crossing the same HTTP seam a Run uses.
5. **The Run refuses localhost** (CONTEXT.md: a measurement taken any other way is not a Run). No escape hatch.
6. **`CONTEXT.md` gains Slot, Rung, Master** (B2's vocabulary; Master is already the generator's and CLAUDE.md's word).

## File structure

| Path | Responsibility |
|---|---|
| `lib/image-size.mjs` | Pixel size of a JPEG/WebP from its header bytes. No deps. |
| `lib/page.mjs` | The page model: start tags in any attribute order/quote style, `<picture>` groups, `<section>` spans, subresource URLs, the inline stylesheet as rules with `@media` contexts, custom-property resolution, WCAG contrast. |
| `images/slots.json` | One description per Slot: master, ratio, widths, sizes, box, optional webp_quality. |
| `tools/build-images.py` | Reads `slots.json`; writes every Rung (both formats, Hero JPEG included); refuses upscaling. |
| `tests/performance-contract.mjs` | The Performance Contract, rewritten on the model + table. |
| `lib/report.mjs` | Pure Report logic: read, check realness, name by UTC fetchTime, summarize, score net of a known artifact. |
| `tools/run.mjs` | `node tools/run.mjs <preview-url>`: perform the Run via the Lighthouse adapter, refuse an unreal Report, write it, print the summary. Exports `performRun` for the recorded-Report adapter. |
| `tests/run.mjs` | Assertions over `lib/report.mjs` + `performRun` using the recorded Reports as the second adapter. |
| `server.py` | Policy table (type, gzip, cache) + public allowlist; 404s never immutable; `0` = ephemeral port, printed flushed. |
| `tests/measurement-server.mjs` | Spawns `python server.py 0`, probes headers/status over HTTP. |
| `CLAUDE.md`, `CONTEXT.md`, `BACKLOG.md`, `llms.txt` | Docs/vocabulary/status updates (main session only). |

export function imageSize(bytes: Uint8Array): { format: 'jpeg'|'webp', width: number, height: number }  // throws on anything else

### `lib/page.mjs`
```js
export async function loadPage(pageUrl: URL): Promise<Page>
export function parseSrcset(value: string): { url: string, width: number|null }[]
export function contrast(hexA: string, hexB: string): number   // WCAG 2.x ratio, #rgb/#rrggbb

Page {
  url: URL, html: string,
  title: string,                      // <title> text, whitespace collapsed
  meta(name): string|undefined,       // <meta name=..> content
  elements(tag): Element[],           // every start tag, document order; attrs lower-cased, any quote style
  sections: Section[],                // <section ...>…</section> spans: {attrs, start, end}
  pictures: Picture[],                // {start, end, source: Element, img: Element}
  scripts: {attrs, inline: string, start, end}[],
  assets: string[],                   // subresource URLs as written, deduped: img src, srcset/imagesrcset candidates, preload href, script src
  hrefs: string[],                    // every href of <a>/<link>
  styles: Stylesheet,
}
Element { name, attrs: Record<string,string>, start, end }      // boolean attribute → ''
Stylesheet {
  rules: { media: string|null, selector: string, declarations: Record<string,string> }[],
  contexts: (string|null)[],          // [null, '(max-width:700px)', ...] in source order
  cascade(selector, media = null): Record<string,string>,   // exact-selector rules, base then media, later wins
  resolve(value): string,             // var(--x) → :root value
}
```

### `images/slots.json`
```json
{ "hero": { "master": "hero.jpg", "ratio": null, "widths": [640, 768, 1200], "sizes": "(max-width: 700px) 100vw, 50vw", "box": ".hero-image" },
  "notebook": { "master": "notebook.jpg", "ratio": [4, 5], "widths": [400, 700], "sizes": "(max-width: 700px) 45vw, 30vw", "box": ".product-image" },
  "mug": { "master": "mug.jpg", "ratio": [4, 5], "widths": [374], "sizes": "(max-width: 700px) 45vw, 30vw", "box": ".product-image" },
  "coffee": { "master": "coffee.jpg", "ratio": [4, 5], "widths": [374], "sizes": "(max-width: 700px) 45vw, 30vw", "box": ".product-image", "webp_quality": 75 } }
```
Rung file: `<slot>-<width>.<webp|jpg>`. `ratio: null` = keep the master's own ratio. Crop/resize arithmetic (shared by generator and contract, integer-exact): landscape-vs-ratio centre crop as in today's `centre_crop`; a rung of width `w` has height `round(w * crop.h / crop.w)`; `w == crop.w` is the crop itself.

### `lib/report.mjs`
```js
export async function readReport(fileUrl): Promise<Report>
export function checkReport(report, previewUrl?: string): string[]     // [] means real; each string names one reason
export function reportName(report): string                             // `${host}-${YYYYMMDDTHHMMSSZ}.json` from fetchTime
export function summarize(report): Summary
export function formatSummary(summary): string
Summary { url, fetchTime, channel, lighthouseVersion,
          scores: { performance, accessibility, bestPractices, seo },   // 0..1 or null
          metrics: { fcp, lcp, tbt, cls },                                 // numericValue
          requests: number, transferBytes: number,
          artifacts: { audit: string, category: string, reason: string, scoreWithout: number }[] }
```
Realness checks: no `runtimeError`; `requestedUrl` host equals the Preview URL host when given and is never `localhost`/`127.0.0.1`; `configSettings.formFactor === 'mobile'` and `throttlingMethod === 'simulate'`; the document request is 200; no request host under `ngrok.com`; at least one same-origin subresource (`.js` or `/images/`). The first two recorded Reports fetch `images.unsplash.com` — external hosts other than ngrok's are *not* a reason. Known artifact: `robots-txt` scored 0 on an `ngrok-free.dev` host → reported with SEO recomputed without it (weighted mean of `auditRefs`, 2-dp rounding like Lighthouse).

### `server.py`
```
python server.py [port]        # 0 → ephemeral; prints "Serving ... on http://localhost:<bound port>/" flushed
POLICY: suffix → (content type, gzip?, cache header). .html/.txt: text, gzip, no-cache. .js/.css: text, gzip, immutable. .webp/.jpg/.ico: binary, no gzip, immutable.
PUBLIC: "/"→index.html, app.v1.min.js, favicon.ico, robots.txt, llms.txt, images/<name>.(webp|jpg). Everything else 404 with Cache-Control: no-cache. No directory index. HEAD mirrors GET headers. HTTP/1.1 keep-alive, Content-Length always set.
```
